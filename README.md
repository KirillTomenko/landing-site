# landing-site

Личный лендинг Кирилла Томенко — визитка и портфолио для фриланса (Python / AI-разработка).

🔗 **Живая версия:** https://landing-site-49r.pages.dev/

## О проекте

Одностраничный сайт-визитка: чем занимаюсь, кейсы из портфолио (с прямыми ссылками на репозитории и живое демо), интерактивный демо-«сканер» задач и форма для связи.

## Стек

- Чистый **HTML / CSS / JS**, без сборщиков и фреймворков
- Шрифты (**PT Serif**, **Inter**, **JetBrains Mono**) самохостятся из `/fonts` — без зависимости от внешнего CDN
- Форма контактов — через [Web3Forms](https://web3forms.com/) (приём форм без своего бэкенда)
- Деплой — **Cloudflare Pages**, автоматически при пуше в `main`

## Структура

```
index.html         — вся разметка, стили и скрипты одним файлом
about-kirill.jpg    — портрет
og-image.jpg        — превью для шаринга в соцсетях/мессенджерах
robots.txt, sitemap.xml — базовое SEO
fonts/               — самохостящиеся шрифты (woff2, кириллица + латиница)
```

## Локальный запуск

Статика, бэкенд не нужен — просто открой `index.html` в браузере или подними любой локальный сервер:

```bash
python3 -m http.server 8080
```

## Демо-сканер задач

Блок «Есть задача, которую делают вручную?» работает полностью на клиенте: оценка происходит по локальным правилам в `index.html` (функция `analyzeTask`), без отправки текста на сервер. Точка будущего апгрейда отмечена в коде — заменить на реальный вызов LLM через API.
